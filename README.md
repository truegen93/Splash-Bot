# Splash (The Confessions Bot)

This repository contains the live source code for Splash. 

## Transparency Notice
This source code is made publicly available strictly as a transparency and auditing measure. In light of data-harvesting and malicious practices within the Discord bot ecosystem, this repository allows users to verify that Splash operates with data minimization and contains no hidden telemetry or tracking.
